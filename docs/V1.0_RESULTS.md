# Reproducible V1.0 selected results

## Reproduction commands

From the repository root with MATLAB R2026a and the documented toolboxes:

```powershell
matlab -batch "run('examples/generateV01Figures.m')"
matlab -batch "run('examples/generateV10Figures.m')"
```

The first command reproduces the clean geometry/source, TDOA, and LMS
diagnostic figures retained from V0.1. The second runs the V1.0 repeated
identical-signal estimator experiment, writes two selected PNGs under
`docs/assets/`, and writes its exact summary CSV below ignored `results/` for
review. No external recording, image, or dataset is an input.

## V1.0 experiment configuration

| Setting | Value |
| --- | --- |
| MATLAB | R2026a Update 4 |
| Sample rate | 48,000 Hz |
| Signal duration | 0.3 s per trial |
| Source signal | Seeded Gaussian broadband signal |
| Microphones | `[-0.06,-0.04]`, `[0.06,-0.04]`, `[-0.06,0.04]`, `[0.06,0.04]` m |
| Actual source | `[0.15, 0.22]` m |
| Reference microphone | 1 |
| Propagation | Direct-path fractional delay, 65-tap Hann-windowed sinc |
| Requested SNRs | Clean (`Inf`), 30, 20, 10, and 0 dB |
| Trials | 5 per SNR; 25 shared signal realizations |
| Seeds | Consecutive integers 26000-26024 |
| Estimators | `lms-peak`, `lms-phase`, `gcc-phat` |
| LMS | 64 taps, step size 0.003, bulk delay 24 samples |
| Initial coordinate guess | `[0.1, 0.15]` m |
| Coordinate bounds | `[-0.5,-0.5]` to `[1,1]` m |

For each seed and SNR, all three estimators receive exactly identical source,
clean microphone, noisy microphone, and noise samples. The experiment
verified that invariant before reporting comparisons.

## Selected numerical summary

Mean localization error in metres, rounded to six decimal places:

| Estimator | Clean | 30 dB | 20 dB | 10 dB | 0 dB |
| --- | ---: | ---: | ---: | ---: | ---: |
| LMS peak | 0.030394 | 0.030394 | 0.030394 | 0.030394 | 0.030320 |
| LMS phase | 0.007126 | 0.007085 | 0.007755 | 0.009383 | 0.161626 |
| GCC-PHAT | 0.026306 | 0.026316 | 0.026175 | 0.026106 | 0.025800 |

All 75 estimator/seed/SNR solver runs succeeded. For LMS phase at 0 dB, the
five-trial median was 0.203053 m and the interpolated 90th percentile was
0.209423 m, showing the substantial realization sensitivity hidden by a
single mean. Exact unrounded statistics are reproduced in
`results/v1.0-estimator-snr-summary.csv` by the generator and are intentionally
not tracked as routine generated output.

In this particular synthetic scene, LMS phase has the smallest mean error
from clean through 10 dB and degrades sharply at 0 dB. GCC-PHAT is less
accurate in the cleaner cases but remains comparatively stable here. The
integer LMS peak result is dominated by its one-sample delay quantization.
These observations are scene-specific and do not establish a universal
ranking.

## Interpretation boundary

The figures are selected reproducible outputs, not benchmark evidence. The
simulation assumes one stationary synthetic source, synchronized microphones,
known 2D geometry and sound speed, direct propagation, and synthetic
broadband excitation. Trial count is deliberately modest. Consult
[`LIMITATIONS.md`](LIMITATIONS.md) and
[`ESTIMATOR_COMPARISON.md`](ESTIMATOR_COMPARISON.md) before interpreting the
results outside this controlled scope.
